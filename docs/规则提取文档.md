## 1. 基本游戏规则（以手册为准）

| 项目 | 手册（京城大师 S2） | 摩卡杯 |
| --- | --- | --- |
| 游戏配置 | 暗牌、有警长、屠边（狼人杀光所有神职或所有平民即获胜） | 同手册 |
| 警长竞选发言 | **120 秒** | 90 秒 |
| 放逐发言 | **150 秒** | 90 秒 |
| 警长发言 | **180 秒** | 120 秒 |
| 遗言 | **150 秒** | 90 秒 |
| 女巫 | 全程不可自救；解药、毒药同一夜最多用一瓶 | 同手册 |
| 平票 | PK 1 轮发言 | 同手册 |
| 投票 | 戴盔、**5 秒**、自倒数开始示票、手举过顶；停止口令前未示票视为弃票；唱票有误时高举并挥动 | 戴盔、5 秒、举手过顶，超时或未举手视为弃票 |

> App 默认发言时长按你的确认取 **90 / 90 / 120 / 90 秒**，剩余 **30 秒**提示、结束提醒；全部可在「发言时长配置」中调整。

### 1.1 警长细则（手册）
- 票权 **1.5 票**；归票 PK、不归票、实际投票与归票不一致（归 A 投 B）时为 **1 票**，且 PK 发言后票权仍为 1 票
- 单死可选择死左/死右发言；多死可选择警左/警右发言；不可抢先发言；有归票权
- 竞选环节狼人自爆 → 竞选延期到第二天，延期竞选阶段无发言；有效自爆两名狼人 → 警徽流失
- 无警长候选人（上警玩家）→ 警徽流失；无警长投票人（警下玩家）→ 按顺序发言退水，退至唯一警上玩家自动当选，退水后仍多于一人则警徽流失
- 第一天竞选因自爆仅剩一名候选人 → 自动当选；第二天延期竞选平票 PK 阶段狼人自爆，视为有效自爆两名狼人 → 警徽流失
- 前任警长出局可选择移交警徽或流失警徽
- App 处理（首批）：**警长竞选环节只记录投警徽票结果**（按你的确认），上述复杂流程用状态记录+法官手动推进支持

### 1.2 自爆（手册）
- 狼人需举手示意，待法官下达「发言暂停」口令后表明自爆意图，由法官判定
- 允许自爆阶段：警长竞选发言、警长竞选 PK 发言、竞选退水及自爆环节、延期警长竞选退水及自爆环节、放逐发言、放逐 PK 发言
- 自爆出局的狼人可选择发表遗言，或在下一个狼人行动阶段指刀
- 摩卡杯范围更窄：仅警长竞选、放逐发言、PK 发言阶段允许

### 1.3 遗言与出局结算顺序（手册）
- 首夜出局及放逐出局的玩家有遗言；猎人、狼王技能发动出局的玩家有无遗言取决于使用技能的玩家
- 结算顺序：**技能结算 > 遗言 > 警徽移交**；技能结算连锁产生新技能结算时，先处理完新技能，再按顺序发表遗言
- 举例：5 号警长（猎人）第三天被放逐 → 5 号发动技能带走 1 号 → 1 号发动带走 7 号 → 例行询问 7 号 → 5 号遗言 → 5 号移交警徽 → 1 号遗言 → 7 号遗言

### 1.4 出局技能发动时限（手册）
- 猎人开枪、狼王开枪、警徽移交：口令下达后 **5 秒倒计时**内举手示意，超时视为无效发动或警徽流失并判罚
- 确认发动后戴盔，有 **15 秒盔内思考时间**明确技能目标号码/警徽移交号码

### 1.5 无警徽时发言起始位置（手册）
- 以现场时间（主裁判计时设备）分钟数除以 12 的余数为首位发言号码（余 0 为 12 号）；余数奇数顺序发言，偶数逆序发言；首位已出局则顺延至第一位存活者，方向不变

### 1.6 击杀/技能发动成功判定（手册）
- 狼人夜间有明确公认击杀目标且多数给出号码手势 → 法官在打铃阶段给确认手势，无异议即击杀成功
- 意见分歧至戴盔/行动结束仍无唯一号码 → 最后一声铃响后给禁止及空过手势，判定**空刀**；以当局裁判多数意见为准
- 其他技能同理：行动结束前未得到明确目标号码手势 → 判定**未发动技能**
- 需给出结果的技能（预言家、纯白之女、狼巫、数学家、石像鬼查验）在玩家确认或默认后给出结果手势

### 1.7 交牌及认输（手册）
- 好人阵营无权交牌/认输
- 多名狼人存活时仅可在夜间行动环节统一认输意见时交牌（石像鬼守墓人、等式悖论版型中技能狼/狼人不可代表不见面的其他狼人交牌）
- 仅剩唯一存活狼人且几乎无获胜可能时，可在白天放逐发言及夜间行动环节交牌；白天交牌当天默认所有存活好人投给该狼人

### 1.8 游戏结束（胜负）判定（手册，屠边）
1. 夜间结束时或放逐投票后，所有狼人均出局，且平民、神职阵营均有存活 → **好人胜**
2. 同一夜间好人与狼人同时达成胜利条件 → **狼人胜**
3. 平民或神职任一阵营全部出局，狼人仍有存活 → **狼人胜**
4. 白天放逐发言环节开始时，狼人阵营明确的最多票数 ≥ 其他身份的最多票数 → **狼人胜**（拍刀/冲票提前结束）

## 2. 夜间行动时长（手册）

| 类别 | 时长 |
| --- | --- |
| 狼人 | 首夜 **90 秒**（剩余 30 秒提示「狼人请迅猛」）；次夜起 **45 秒**（剩余 15 秒提示） |
| 需发动技能的神职（预言家、女巫等） | **15 秒** |
| 只需确认状态/信息（猎人、守墓人等） | **5 秒** |
| 只需确认身份（白痴等） | 首夜 5 秒，次夜起不再唤醒 |
| 石像鬼（特殊） | 首夜第一次睁眼 **5 秒**；首夜第二次睁眼 **15 秒**；次夜起分阶段「验人 15 秒 + 击杀 15 秒」 |
| 诡狼（特殊） | 首夜「确认其他狼人 10 秒 + 诡计 15 秒」；次夜起「诡计 15 秒 + 击杀 15 秒」 |

- 起止：自「XX 请睁眼」口令结束起，至倒计时铃声结束止；请睁眼、请闭眼口令不计入行动时长
- 摩卡杯为：狼人首夜 60 秒/次夜 30 秒；神职技能 15 秒、确认状态 5 秒
- **出厂默认（已确认）：手册时长（狼人 90/45 秒等）**；摩卡杯版型调用时是否自动套用 60/30 秒，在版型配置中作为该版型默认值，全局可改
- App 中以上时长全部可配置，特殊角色支持**分阶段计时**

## 4. 角色技能说明（手册原文要点）

### 4.1 通用角色
- **狼人**：每夜可与其他狼人共同击杀一名玩家
- **预言家**：每晚查验一名玩家身份，法官告知其为好人或是狼人
- **女巫**：整局解药、毒药各一瓶；解药未使用时夜间告知当夜被狼人袭击的玩家；全程不可自救；同一夜最多使用一瓶药
- **猎人**：出局时可选择开枪带走场上一名玩家；被女巫毒杀时无法发动（梦魇/摄梦系列版型中被梦亡也无法发动）；法官夜间告知猎人开枪状态
- **白痴**：放逐投票被公投出局时翻牌（存活状态为已出局），被宣布为白痴，可存场上至下一个放逐投票环节前
- **平民**：夜间无行动，白天找出狼人并放逐
- **狼王**：场上仍有其他狼人存活时出局可开枪带走一人；自爆、被女巫毒杀（及被梦亡）时无法发动
- **守卫**：每晚守护一名玩家免狼袭；连续两夜不能守同一人；与女巫解药同作用一人时（同守同救）该玩家依然出局，且解药视为已使用

### 4.2 特殊神职/狼牌
- **梦魇**：先于其他狼人发动技能；每夜恐惧一名玩家使其当夜无法发动技能；恐惧到狼人时狼人当夜无法袭击；连续两晚不可恐惧同一人
- **摄梦人**：每晚必须选择一名除自己外的玩家成为梦游者，梦游者免疫夜间一切伤害；连续两夜选择同一玩家则该玩家梦亡出局；摄梦人夜间出局时其当夜梦游者一并梦亡出局；被梦亡出局的猎人无法发动技能
- **血月使徒**：自爆时神职阵营接下来一个夜间行动阶段无法发动技能；为最后一名存活狼阵营玩家时被放逐不直接出局，再次进入天黑，并与其当夜击杀的玩家一起出局
- **猎魔人**：自第二夜起可发动狩猎；狩猎对象为狼人则该狼人出局，为好人则猎魔人失败出局；女巫毒杀猎魔人时猎魔人不出局且毒药视为已使用
- **狼巫**：每晚查验一名玩家具体身份；自第二夜起查到纯白之女，纯白之女直接被查验出局
- **纯白之女**：每晚查验一名玩家具体身份；自第二夜起查到狼人阵营玩家，该玩家直接被查验出局
- **石像鬼**：与其他狼人互不见面；每晚查验一名玩家具体身份；狼人阵营仅剩石像鬼存活时方可行使基本击杀技能；不可自爆；时长见 §2
- **守墓人**：每一夜被告知昨日被放逐出局玩家的身份为好人或是狼人
- **诡狼**：知道其他狼人身份但其他狼人不知诡狼；仅剩诡狼存活时方可行使击杀；夜间可对一名玩家使用诡计，使其当夜被数学家查验时视为相反阵营结果；诡计连续两夜不能选同一目标，整局只能生效一次；不可自爆；时长见 §2
- **数学家**：自第二夜起每晚可查验其他两名玩家身份是否同阵营（同阵营「等式成立」拇指向上，不同阵营「等式不成立」拇指向下）；首次验出等式不成立时，次夜自动获得持续一夜的一次性守卫护盾；每名其他玩家只可被查验一次；解药与数学家护盾同时作用时数学家依然出局且解药视为已使用

### 4.3 机械狼通灵师版型角色（用户确认规则）

- **通灵师**：每晚可查验一名玩家的**具体身份**（而非好人/狼人阵营）。设计逻辑与预言家一致，区别仅在查验结果粒度；从代码角度与预言家同构（行动类型 = 查验具体身份）
- **机械狼**：
  - 与其他狼人**互不见面**；夜间单独行动
  - 整局仅有**一次学习机会**：选择一名其他玩家「学习」，知晓其真实身份并**永久获得**其技能
  - 学习结果分支：
    - **平民**：不获得任何技能（最不利情况）
    - **通灵师**：获得查验技能，从下一晚起每晚可查验一名玩家的具体身份
    - **女巫**：获得**一瓶毒药**，从下一晚起可毒杀一名玩家（注：部分规则中该毒药可能无视解药，App 做成版型开关，默认按普通毒药处理，待你定）
    - **守卫**：获得守护技能，从下一晚起每夜选择一名目标守护（机制同守卫）；**若女巫毒药使用到机械狼守护的目标上，毒药反弹，毒死女巫**
    - **猎人**：获得开枪技能，出局时可开枪带走一名玩家（机制同猎人）
    - **狼人**：获得**一次双刀技能**；仅当场上其他狼人全部出局、机械狼获得刀人权后才能使用；技能刀为**破盾刀**——可直接杀死未被守护的目标，也可先抵消守卫守护再以普通刀击杀该目标，即两刀砍同一人必死
- App 建模要点：机械狼夜间行动分「学习阶段（一次性）」与「学得技能行动阶段」；行动记录需存学习目标、学得技能、技能使用情况；获得刀人权时机 = 其他狼全部出局（同石像鬼判定）

### 4.4 摩卡杯专属角色（手册没有，用于 15 人版型）
- **狼美人**：每夜魅惑一人，自己出局时魅惑对象一同出局（同守同救规则不变）
- **骑士**：可在白天翻牌决斗；决斗狼人则该狼人出局，决斗好人则骑士出局
- **机械狼（摩卡杯 15 人版）**：首夜可学习一名好人技能（获知身份并可复制使用一次），学习后永久获得该技能但不可重复学习；狼刀与普通狼人一致
  - 与 12 人「机械狼通灵师」版的差异：以版型为单位分别配置，互不混用

## 5. 积分规则（手册为默认，摩卡杯差异已标注）

每局总分 = **胜负分 + 行为分 + 投票分 + 特殊分 − 违规扣分**（另有 MVP/SVP/背锅评选分）

### 5.1 胜负分
- 获胜阵营 **+5**/人；失败阵营 **+0**/人

### 5.2 行为分（手册 13 个角色）

| 角色 | 加分项 | 减分项 |
| --- | --- | --- |
| 预言家 | 警长竞选获警徽 +0.5；第一天有狼人白天被放逐或自爆 +0.5 | 无有效验人每次 −0.5（存活玩家都已查验导致无人可验不扣） |
| 女巫 | 毒杀狼人 +1（毒杀吞毒自爆狼人、同时被摄梦人梦亡的狼人不加分） | 毒杀好人 −1 |
| 猎人 | 枪杀狼人 +1 | 枪杀好人 −1 |
| 守卫 | 守中中刀好人且无同守同救 +0.5/次，**上限 +1**；同守同救好人 −0.5（同守同救狼人不扣分） | — |
| 摄梦人 | 守中一次好人或梦亡一个狼人 +0.5，上限 +1 | 梦亡一个好人或守中一个狼人 −0.5 |
| 猎魔人 | 狩猎狼人 +0.5，上限 +1（狩猎吞猎自爆狼人、同时死于毒杀的狼人不加分） | 狩猎好人 −1 |
| 数学家 | 激活护盾效果 +0.5 | 无有效验人每次 −0.5（存活玩家都已查验或不足 2 人可验不扣） |
| 纯白之女 | 警长竞选获警徽 +0.5；查验致狼人出局 +0.5，上限 +1（验杀吞验自爆狼、同时死于毒杀的狼不加分） | 被狼巫查验出局 −0.5 |
| 狼王 | 开枪带走带药女巫（至少单药）、守卫、摄梦人 +0.5 | 被梦亡、被毒杀 −0.5 |
| 诡狼 | 技能生效 +0.5 | — |
| 梦魇 | 恐惧有药（至少单药）女巫、摄梦人、守卫 +0.5，上限 +1 | 恐惧狼人 −1 |
| 血月使徒 | 存活到游戏结束，或自爆击杀带药女巫（至少单药）、猎魔人 +0.5 | 被毒杀、被猎杀 −0.5 |
| 狼巫 | 查验致纯白之女出局 +0.5 | 被纯白之女查验出局 −0.5 |

**冲突结算标准（手册脚注 5、6）：**
- 同阵营技能目标冲突（如同狩同毒）：以**实际死亡原因**为结算标准
- 不同阵营技能目标冲突（如同刀同毒）：以**技能发动过程**为结算标准
- 同刀同毒、同刀同梦、梦游吃毒好人、毒杀猎魔人等好人阵营实际失误情形，好人阵营不计对应分数

**摩卡杯差异：**
- 守卫守中上限 **+2**（手册 +1）
- 投票分上限 **+2**（手册 +1，见 §5.3）
- 另有骑士（决斗狼成功 +1 / 决斗好人 −1）、狼美人（魅惑带走神职 +0.5 / 被毒杀或被骑士决斗 −0.5）、机械狼（复制技能并成功使用一次 +0.5 / 学习后未使用或失败 −0.5）
- 狼王加分项为带走带药女巫/守卫（无摄梦人）

**「机械狼通灵师」版型行为分（规则文件未给出，建议默认值，配置页可调）：**
- 通灵师：套用预言家方案（获警徽 +0.5；第一天有狼被放逐/自爆 +0.5；无有效查验每次 −0.5，全场可验对象都已查验时不扣）
- 机械狼：复制（学得）技能并成功使用一次 +0.5；学习后未使用或使用失败 −0.5
- 女巫/守卫/猎人：套用手册同角色方案（守卫守中上限 +1）

### 5.3 投票分（手册）
- **不计票人员**：警长竞选环节投票、预言家、纯白之女、狼人（机械狼通灵师版型中通灵师同理不计票；纯白之女版型中不含预言家）——按版型实际角色配置生效
- 放逐投票投给狼人 **+0.5**，**上限 +1**；投给好人或弃票 **−0.5**
- 平票 PK 计票规则：
  1. PK 台上的玩家以第一次投票为准
  2. PK 台上有狼人自爆，所有玩家以第一次投票为准
  3. 出现第二次投票结果时，除 PK 台上的所有玩家以第二次投票为准
  4. PK 台上均为好人时，第一次投票投给狼人的玩家第二次弃票不计投票分
- 摩卡杯：上限 +2；PK 台上玩家第二次投票不计

## 7. App 规则配置化设计要点（供开发直接引用）

1. **版型（BoardConfig）**：人数、狼队组成、神/民组成、胜利条件（屠边）、各角色行为分方案、夜间唤醒顺序
2. **角色（Role）**：阵营（狼/神/民）、夜间行动类型（无行动/确认身份/确认状态/查验好人狼人/查验具体身份/击杀/解药/毒药/守护/恐惧/梦游/狩猎/诡计/等式查验/学习/魅惑/决斗/双刀）、默认时长与分阶段时长、可否自爆、出局是否可开枪/开枪限制条件
3. **行动结果结构化点选项**（按你确认的「法官逐项点选」）：目标座位号 + 行动类型（击杀/空刀/查验结果/开药/开药对象/毒人/守护/恐惧/梦游/狩猎/决斗/学习/魅惑/诡计/双刀/不发动），这是行为分自动计算的输入
4. **机械狼特殊状态机**：未学习（可学习一次，记录学习目标→学得技能）→ 已学习（平民：无后续行动；通灵师：每夜查验；女巫：一瓶毒药；守卫：每夜守护+毒药反弹判定；猎人：出局开枪标记；狼人：其他狼全出局后获得刀人权+一次性破盾双刀）
5. **积分规则（ScoreRule）**：每条规则含角色/适用版型、触发条件、分值、上限、是否启用；调用版型时载入该版型的角色行为得分集
6. **发言配置**：四类发言时长 + 提前提示秒数（默认 30）+ 结束提醒
7. **投票计分开关**：身份排除（预言家、纯白之女、狼人不计）、PK 轮次规则按版型可配
8. **特殊分参数化**：点狼/点神所需张数（12 人 4 张 +1 / 15 人 5 张 +2）跟随版型人数
9. **评选**：每局结束录入 MVP、SVP（必填）、背锅（狼胜时可选）
